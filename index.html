The Waking State of Your App

In classical Japanese, Utsutsu (現) refers to reality and the waking world. We believe application state should be a direct, fully conscious reflection of truth—not a dream of nested complex abstractions.

1. Cells (Atomic Reality)

The smallest writable units of state. No proxy magic or obscure listeners. Just raw, predictable leaf nodes that hold the absolute truth.

2. Lenses (Reflections)

Cached derived state that automatically tracks dependencies. active/passive lifecycles subscribe when components wake up, and sleep when they unmount.

3. Intents (Waking Actions)

State doesn't drift implicitly. It transitions via named Intents—explicit, predictable, and pure functions. Action and reducer in one line.

4. Frames (Boundaries)

Group multiple state updates inside a transactional frame. Subscribers are notified exactly once when the frame exits. 0 layout thrashing.

// 1. Define atomic state
const store = createUtsutsu({
  hero: { name: "Rimuru", level: 35, hp: 1200 },
  mana: 85,
  logs: 2
});

// 2. Define derived read-only Lenses
const heroLens = store.lens("heroStats", s => s.hero);
const manaLens = store.lens("manaPool", s => s.mana);
const logsLens = store.lens("systemLogs", s => s.logs);

// 3. Define mutators (Intents)
const trainHero = store.intent("train", s => ({
  ...s,
  hero: { ...s.hero, level: s.hero.level + 1 },
  logs: s.logs + 1
}));

const castSpell = store.intent("cast", s => ({
  ...s,
  mana: Math.max(0, s.mana - 30),
  logs: s.logs + 1
}));

Comparison: Utsutsu vs Others

No selectors at the hook site. Define your lenses once, let Utsutsu manage the dependency tree.


// store.ts
import { createUtsutsu } from "utsutsu";

export const store = createUtsutsu({
  hero: { name: "Rimuru", level: 35, hp: 1200 },
  mana: 85
});

// Derived states are Lenses—evaluated once and cached
export const powerLens = store.lens("power", s => 
  s.hero.level * 100 + s.mana
);

export const trainHero = store.intent("train", s => ({
  ...s,
  hero: { ...s.hero, level: s.hero.level + 1 }
}));

// store.ts
import { create } from "zustand";

interface RPGState {
  hero: { name: string; level: number; hp: number };
  mana: number;
  trainHero: () => void;
}

export const useRPGStore = create((set) => ({
  hero: { name: "Rimuru", level: 35, hp: 1200 },
  mana: 85,
  trainHero: () => set(s => ({
    hero: { ...s.hero, level: s.hero.level + 1 }
  }))
}));

// Component.tsx
import { useRPGStore } from "./store";

function HeroBadge() {
  // ⚠️ Rerenders whenever ANY mana or hp value in the store changes
  // unless you write complex custom slice selectors/shallow checkers!
  const hero = useRPGStore(s => s.hero);
  const mana = useRPGStore(s => s.mana);
  const power = hero.level * 100 + mana;
  
  const trainHero = useRPGStore(s => s.trainHero);
  return ;
}

import { createSlice } from "@reduxjs/toolkit";

const rpgSlice = createSlice({
